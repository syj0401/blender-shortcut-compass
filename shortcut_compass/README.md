# Shortcut Compass / 快捷键助手 0.6.0

在 Blender 编辑区域底部持续显示原生快捷键提示条：**空闲时显示当前编辑器和模式的常用键，按住前缀时显示下一步可以接哪些键。** 常用键包含 `G / R / S` 等单键及组合键；具体选项根据当前上下文、选择状态与实际用户键位配置变化。选项按用途分组排序，自动换行展开。

例如某项操作被绑定为 `Ctrl + Shift + S`：按住 `Ctrl` 时，提示 `Shift · 更多组合(N)`，同时显示此时可直接完成的操作，如 `S · 保存`；继续按住 `Shift`，才显示 `S · 操作名称`。`N` 是这一分支包含的组合数量，操作名称采用你的实际 Blender 绑定。

原交付说明记录的测试环境：Blender 5.2.0。扩展声明最低版本为 4.2，其他版本未实机验证。

## 安装和打开

1. Blender → 编辑 → 偏好设置 → 获取扩展，打开右上角菜单，选择「从磁盘安装 / Install from Disk」。
2. 选择 `shortcut_compass-0.6.0.zip` 并启用；已有旧版本时安装此包更新。
3. Blender 顶部「窗口 / Window」菜单 →「快捷键助手：显示悬浮提示」。也可在 3D 视图按 N，在「快捷键」侧栏打开。
4. 把鼠标移入正在使用的编辑区域，即可查看常用键；按住 `Ctrl`、`Shift`、`Alt` 或 `Win / Cmd`，切换为下一步按键。也可启动 Blender 的移动操作，查看操作过程中可用的轴约束、确认与取消。

悬浮提示由 Blender 自身绘制，不打开外部窗口，也不需要外部 Python。

## 使用

- 空闲时显示「常用快捷键」，每项显示完整键位及操作名称。切换编辑器或模式后更新常用选项，物体模式与网格编辑模式可显示不同操作。
- 按住前缀时，已按住的键显示一次。每项只显示下一步的键及操作名称；仍需增加修饰键的组合归为「更多组合(N)」分支。
- 继续按住修饰键，进入对应分支；松开这个键，回到上一层。全部松开且没有正在进行的模态操作时，自动回到常用快捷键。
- 在底部横条中展开当前层所有选项，空间不足时自动换行，无需翻页。编辑区域太小、无法容纳全部选项时，会提示扩大编辑器。
- 按文件、编辑、视图等用途排列选项；模态操作中，轴约束和确认 / 取消分别相邻显示。
- 相同效果的按键共享一条操作说明，每个键仍完整显示。例如实际绑定为确认的 `Enter`、数字键盘 `Enter`、`Space`、左键可共用「确认」说明。同类参数操作保留各键对应的值，如 `0–5` 的细分等级。
- 「更多组合」分支用淡强调色、`›` 和描边标出，便于识别下一层入口。
- 按 `G` 启动移动后，即使松开 `G`，仍显示 `X / Y / Z` 约束、确认和取消。提示持续到 Blender 中的移动操作实际结束，再回到常用快捷键。
- 按键照常交给 Blender；提示条只展示当前可用选项。
- 在 N 侧栏或扩展偏好设置中调整字号。
- 在「窗口」菜单或 N 侧栏隐藏提示；「停止」会同时停止本机数据桥。

空闲的常用列表从当前编辑器与模式的常用操作中筛选，结合当前选择状态和操作可用性检查，并读取实际用户键位。每项只显示已验证的主要绑定；已移除、禁用或未绑定的操作不显示，也不会用搜索操作的文字替代快捷键。列表没有任意截取前几项，不会在空闲时展开所有插件键位。

按住前缀后的候选仍读取当前上下文中全部适用的实际绑定，包括 Blender 用户键位、自定义组合和已启用插件的适用键位；禁用的绑定不会显示。同一按键事件出现多个绑定时，按适用键位的优先级筛选，实际执行由 Blender 决定。

提示条只负责展示，不执行候选操作。按下最后一个键时，原快捷键照常执行。普通字母只有在实际键位使用该键作为 `key_modifier`，或 Blender 已实际进入相应模态操作时，才会参与后续提示。

模态提示支持具有可查询关联模态键位的实际活动操作，如移动、旋转、缩放（通常为 `G / R / S`）；按键松开不会提前结束提示。Blender 未公开原生模态键位的逐项可用状态和宏当前子操作，因此部分宏及操作内部特殊状态可能无法完整反映，可同时参考 Blender 底部状态栏。

## 可选 MCP 连接

随附 `mcp_bridge` 可让 Codex 读取当前上下文、常用快捷键、按住的键、当前层下一步选项与模态操作状态，参阅仓库的 `docs/mcp-setup.md` 与 `mcp_bridge/README.md`。只有可选 MCP 服务需要外部 Python。

在 N 侧栏点击「启动数据桥」，默认监听 `127.0.0.1:18764`。使用插件按钮复制连接令牌。快照的 `display_mode` 为 `common`、`prefix` 或 `modal`。空闲时，`common_shortcuts` 为常用完整键位，`common_count` 是其长度；`next_steps` 为空且 `candidate_count` 为 0。按住前缀或正在模态操作时，`next_steps` 为当前层每个按键的独立记录，附带用途分组及共享说明的展示元数据；`candidate_count` 等于该列表长度。界面展示组数单独统计。`recommendations` 在空闲时为常用完整绑定，在前缀或模态状态下为完整匹配绑定；`binding_count` 是其长度。`input` 记录按住的键，`modal` 提供实际模态操作信息，无模态操作时为 `null`。

令牌存放在 Blender 插件偏好设置中；跨重启复用 MCP 配置时，在生成令牌后保存 Blender 偏好设置。端口或令牌变更后，停止并重启本机数据桥，更新 MCP 配置。

## 停止与卸载

在 N 侧栏「快捷键」中点击「停止」，或在偏好设置中禁用 / 卸载扩展。插件不会改写你的现有键位配置。
